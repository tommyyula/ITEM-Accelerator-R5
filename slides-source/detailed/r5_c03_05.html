Object Database｜数据语义Object Database | Data semantics

由跨角色协同，将原始异构数据构建成可引用的数据语义Cross-role collaboration turns raw, heterogeneous data into referenceable data semantics

01 · RAW

原始表与字段Raw tables and fields

  • 数据散落在表与字段中
  • 尚未形成统一业务含义
  • 难以被业务与 AI 直接引用
  • Data is scattered across tables and fields
  • No shared business meaning has been formed yet
  • Hard for business users and AI to reference directly
02 · SEMANTICS

可引用的数据语义Referenceable data semantics

  • 对表、字段、关系做语义定义
  • 供本体与应用引用
  • 原始真实数据 → 统一语义
  • Define the meaning of tables, fields and relations
  • Referenced by the ontology and applications
  • Raw real data → unified semantics
协同构建BUILT TOGETHER

FDE + 业务专家 + 技术专家 → 原始异构数据构建成数据语义FDE + business experts + technical experts → raw heterogeneous data becomes data semantics

要点Key pointFDE + 业务专家 + 技术专家协同完成语义化，供本体与应用引用FDE, business experts and technical experts jointly complete the semantics, for the ontology and applications to reference
