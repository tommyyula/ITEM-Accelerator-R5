演示：一箱破损电池，三个应用串起发现 → 派工 → 入坏货区Demo: one damaged battery carton, three apps from discovery to dispatch to the damage zone

系统里它还是一箱好货，明天就可能被拣走发给客户。巡检员和主管各自对 Agent 说出需求；终点不是表单提交，而是有证据的业务状态变化。In the system it is still good stock and could ship to a customer tomorrow. A patroller and a supervisor each tell the Agent what they need; the end point is not a form submit but an evidenced change in business state.

01 · 巡检员 · 手机01 · PATROLLER · MOBILE

“看到破损就拍照上报”“Photo and report any damage I see”

  • 生成BUILTAgent 查本体与上报接口，给出计划卡；同意后生成巡检任务页（Dynamic Task）。The Agent checks the ontology and report API, proposes a plan, then builds a patrol task (Dynamic Task).
  • 试用TRY扫库位、扫 LPN 自动带出客户与物料；没拍照不能提交。Scanning location and LPN fills customer and item; no photo, no submit.
  • 结果RESULT生成 Inventory Issue，货况 Good → Damaged，这批货立即不可拣。An Inventory Issue is created and condition goes Good → Damaged; the stock can no longer be picked.

当场生成、当场试用；好用就存为 Inventory Patrol 任务类型。Built and tried on the spot; if it works, save it as the Inventory Patrol task type.

02 · 主管 · WEB02 · SUPERVISOR · WEB

“做一个破损转移工作台”“Build me a damage-move workbench”

  • 生成BUILTAgent 写数据查询，先用真实数据预览，再起草页面（Dynamic Page）；草稿只有作者可见。The Agent writes the query, previews real data, then drafts the page (Dynamic Page), visible only to its author.
  • 发布RELEASE系统按页面调用的接口算出所需权限，主管确认后发布。WMS derives the required access from the APIs the page calls; the supervisor confirms and publishes.
  • 结果RESULT勾选两条 Issue、指派执行人，创建 Move Damage 任务；Issue 变为 In Progress。Select two Issues, assign a worker and create a Move Damage task; the Issues move to In Progress.

页面只组合现有接口和已有的 Move Damage 任务类型。The page only combines existing APIs and the existing Move Damage task type.

03 · 主管搭建 · 执行人手机执行03 · SUPERVISOR BUILDS · WORKER RUNS

“把坏货搬到坏货区”“Move damaged stock to the damage zone”

  • 生成BUILTAgent 只组合一个标准步骤 Move Inventory，目的地按货况指向坏货区；试运行后发布。One standard step, Move Inventory, routed to the damage zone by condition; published after a trial run.
  • 执行RUN扫错库位直接被拒；按建议扫描放到 DMG-01，任务关闭。A wrong location is rejected; scan and place at the suggested DMG-01, and the task closes.
  • 结果RESULT两条 Issue 自动 Resolved：Open → In Progress → Resolved。Both Issues resolve automatically: Open → In Progress → Resolved.

从上报到结案形成闭环，每一步可追溯到人和版本。A closed loop from report to resolution, every step traceable to a person and a version.
